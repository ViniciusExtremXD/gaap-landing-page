# Autorização desta prévia pública

Registro: `gaap-pages-preview-2026-09-04` — 4 de setembro de 2026.

O solicitante havia confirmado na conversa: “Sim, autorizou fotos e vídeos próprios para o protótipo local”. Depois de receber a proposta local e seu relatório, pediu explicitamente: “no final, suba para o github e faça deploy no gh pages e me de o link”. Esse pedido autoriza a publicação desta mesma proposta no repositório e no GitHub Pages abaixo.

- Destino da prévia: <https://viniciusextremxd.github.io/gaap-landing-page/>
- Escopo no manifesto: `public-preview`.

O registro documenta a instrução do solicitante para esta publicação. Não declara uma licença irrestrita concedida pela ONG, transferência de direitos autorais, autorização para outros domínios ou endosso oficial do resultado.

## Validação

`npm run validate:publish` exige que cada mídia `public-preview` tenha este registro associado, que seu identificador, fonte e arquivo correspondam à lista autorizada e que o destino seja exatamente o GitHub Pages registrado. Mídias `local-preview` ou `pending` usadas continuam sendo rejeitadas na publicação. Uma troca de arquivo, de fonte ou de destino exige atualização explícita da autorização; o estado `public-preview` não é uma liberação genérica.
